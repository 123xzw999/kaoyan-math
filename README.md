# 考研数学拿高分

一个零依赖、双击即用的考研数学学习网站：**公式库 + 二级结论 + 题库刷题 + 历年真题 + 手写答题板**。

打开方式：双击 `index.html`（或本地起个静态服务器）。

---

## 一、功能一览

| 模块 | 内容 |
|---|---|
| **首页** | 竹墨动态背景 + 10 句励志语录（逐字显现、左右滑动/拖拽切换、每句不同中文字体） |
| **公式库** | 5 大类 / 31 章 / 94 小节，覆盖高数、线代、概率与数理统计；左侧章节树 + 关键词搜索 |
| **二级结论** | 18 张结论卡片（二级结论 / 多级结论 / 常用不等式），标注「秒杀」结论 |
| **题库刷题** | **198 道**精编题（高数 97 / 线代 50 / 概率 51）；按科目、章节筛选；选择题自动判分，填空与解答题自评 |
| **历年真题** | 8 套（2018—2025 数学一/二/三），**123 道**题目原文，含答案与解析，标注可信度 |
| **手写答题板** | 点「开始答题」弹出作业本横线纸；笔 / 橡皮、4 档粗细、5 种颜色、撤销、清空、存为图片 |
| **备考指南** | 零基础起步、三科分工、180 分钟时间分配、全年四轮节奏、高频考点地图、十大失分点 |

## 三、几个使用细节

**数学公式**：全部用 LaTeX 书写，由 KaTeX 本地渲染。数据文件里 `$...$` 为行内公式、`$$...$$` 为独立公式。

**答题进度**：保存在浏览器 `localStorage`（键 `ky_answers_v1`），换设备不会同步。

**手写答题板**：
- 弹出后底部工具栏可切笔 / 橡皮、4 档粗细、5 种颜色；
- 「存为图片」会导出带米色底 + 横线的 PNG，方便贴进错题本；
- 快速打开空白草稿纸：访问 `index.html?pad=1`。

**静态模式**：`index.html?anim=off` 会关闭所有入场动画与飘落竹叶（也自动响应系统的「减少动态效果」偏好）。

## 四、关于真题的诚实说明

考研数学是**全国统考，不分省份**，所以本站按「年份 × 科目」编排。

真题正文在网络上几乎都是**扫描图片或付费文档**，纯文本抓取只能得到骨架。因此本站收录的每一道题都标注了可信度：

| 标记 | 含义 |
|---|---|
| **原文** | 题干、选项、答案均可读，接近官方原卷（2019 数三、2021/2022/2023 数一、2018 数一） |
| **OCR** | 来自扫描件还原，个别表达式可能与原卷有出入 |
| **回忆版** | 考后回忆整理，题序或表述可能有改动 |

凡解析中标注「**待核验**」处（多为 OCR 乱码或题干残缺），请务必以**官方原卷**为准——不要把有疑问的答案当成标准答案背下来。

题库中的 198 道题是按考研大纲与高频考点自行编写/改编的练习，用于巩固知识点，不是真题。

## 五、重新生成数据

`tools/` 下是数据生成脚本，内容改动后重跑即可：

```bash
python tools/gen_formulas.py      # 公式库
python tools/gen_conclusions.py   # 二级结论
python tools/gen_bank_gs.py       # 高数题库
python tools/gen_bank_xd.py       # 线代题库
python tools/gen_bank_gl.py       # 概率题库
python tools/gen_exams.py         # 历年真题
python tools/e2e_test.py          # 端到端交互自测
```
